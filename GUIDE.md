# Echo Arcade – Publish Guide

## All files (everything goes in the ROOT of the repo, no sub-folders)
index.html, play.html, echo-vault.html, arcade.css, style.css, common.js, games.js, hub.js,
game.js (Echo Vault), g-shooter.js, g-summoner.js, g-glitch.js, g-daily.js, g-detective.js,
g-factory.js, g-punch.js, g-mini.js, about.html, privacy.html, contact.html, ads.txt

## Update your existing repo (PowerShell, inside D:\Echo Vault)
1. Copy ALL the new files into the folder and let them replace the old index.html, about.html,
   privacy.html and contact.html.
2. Put your real email into contact.html.
3. Run:
   git add .
   git commit -m "Echo Arcade: 15 games"
   git push
4. Render redeploys automatically in about a minute.

## AdSense tips
- Use a custom domain, and check yourdomain.com/ads.txt opens.
- Each game page has a how-to-play and tips text, which gives AdSense real content to review.
- Share the site on Reddit (r/WebGames), itch.io, Discord to get real visitors.
- Never click your own ads.
